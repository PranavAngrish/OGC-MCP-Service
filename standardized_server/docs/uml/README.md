# UML Diagrams

These PlantUML sources document the experimental OGC API MCP reference server
from three complementary viewpoints:

| Diagram | Purpose |
| --- | --- |
| `system-architecture.puml` | Complete component and deployment view |
| `internal-classes.puml` | Python package responsibilities and dependencies |
| `process-execution-sequence.puml` | Discovery, process execution, and asynchronous job flow |

Render every diagram with the PlantUML CLI:

```bash
plantuml standardized_server/docs/uml/*.puml
```

The source files can also be previewed directly with a PlantUML editor plugin
or pasted into a PlantUML-compatible renderer.
